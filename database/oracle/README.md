# GVMS Oracle Database Schema Deployment Guide

This directory contains the deployment scripts necessary for running the GVMS backend with an **Oracle Database** provider.

## Files

* **`init_oracle.sql`**: Contains the full Oracle-compatible DDL schema (tables, foreign keys, constraints, and indexes) mapped from PostgreSQL, along with metadata seeds.

---

## Dialect Mapping Details

To support Oracle DB compatibility, the database schema maps PostgreSQL structures to their Oracle equivalents as follows:

| PostgreSQL Type | Oracle Equivalent | Details / Implementation |
| :--- | :--- | :--- |
| `SERIAL` / `BIGSERIAL` | `NUMBER GENERATED BY DEFAULT AS IDENTITY ON NULL` | Built-in auto-incrementing identity specification (12c+). |
| `UUID` | `VARCHAR2(36)` | Defaults to formatted GUIDs generated via: `LOWER(REGEXP_REPLACE(RAWTOHEX(SYS_GUID()), '([A-F0-9]{8})([A-F0-9]{4})([A-F0-9]{4})([A-F0-9]{4})([A-F0-9]{12})', '\1-\2-\3-\4-\5'))` |
| `BOOLEAN` | `NUMBER(1)` | Constrained with check values of `(0, 1)` representing `(False, True)`. |
| `JSONB` / `JSON` | `CLOB` with JSON constraint | Handled as `CLOB` with `CHECK (col IS JSON)` to support standard JSON operations (12c/18c/19c compatibility). |
| `TEXT` | `CLOB` | Oracle-native Character Large Object field. |
| `TEXT[]` / `VARCHAR[]` | `VARCHAR2(1000)` / `CLOB` | Simulated array structures stored as serializable JSON strings. |
| `DOUBLE PRECISION` | `DOUBLE PRECISION` | Standard Oracle representation for floating-point fields. |

## Deployment Steps

1. **Database Credentials & User Setup**:
   Ensure you have a database user with DDL creation rights (e.g., `CREATE TABLE`, `CREATE INDEX`, `CREATE VIEW`, etc.).
   
2. **Execute Schema DDL**:
   Run the initialization script against your target Oracle schema using SQL*Plus, SQL Developer, or any database client:
   ```sql
   @init_oracle.sql
   ```

3. **Backend Environment Configuration**:
   Update your project's environmental configuration (e.g. `.env` or `production.env` at the project root) to target the Oracle Database:
   ```ini
   DATABASE_PROVIDER=oracle
   ORACLE_USER=ongc_user
   ORACLE_PASSWORD=YourPassword Here
   ORACLE_HOST=oracle_database_host
   ORACLE_PORT=1521
   ORACLE_SERVICE_NAME=ORCL
   ```
