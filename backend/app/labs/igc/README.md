# IGC / CCUS / Inorganic Geochemistry Laboratory Backend

This directory is designated for the IGC / CCUS / Inorganic Geochemistry Laboratory backend module code.

## Planned Sub-Features
When implemented, this backend module will support:
- API routers under `api/v1/endpoints/igc.py` (or a dedicated package)
- Database models under `models/igc.py`
- Pydantic schemas under `schemas/igc.py`
- CRUD helpers under `crud/crud_igc.py`
