# Stable Isotope Laboratory Backend

This directory is designated for the Stable Isotope Laboratory backend module code.

## Planned Sub-Features
When implemented, this backend module will support:
- API routers under `api/v1/endpoints/isotope.py` (or a dedicated package)
- Database models under `models/isotope.py`
- Pydantic schemas under `schemas/isotope.py`
- CRUD helpers under `crud/crud_isotope.py`
