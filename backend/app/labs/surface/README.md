# Surface Geochemistry, Exploration & Microbiology Laboratory Backend

This directory is designated for the Surface Geochemistry, Exploration & Microbiology Laboratory backend module code.

## Planned Sub-Features
When implemented, this backend module will support:
- API routers under `api/v1/endpoints/surface.py` (or a dedicated package)
- Database models under `models/surface.py`
- Pydantic schemas under `schemas/surface.py`
- CRUD helpers under `crud/crud_surface.py`
