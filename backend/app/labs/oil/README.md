# Oil Laboratory Backend

This directory is designated for the Oil Laboratory backend module code.

## Planned Sub-Features
When implemented, this backend module will support:
- API routers under `api/v1/endpoints/oil.py` (or a dedicated package)
- Database models under `models/oil.py`
- Pydantic schemas under `schemas/oil.py`
- CRUD helpers under `crud/crud_oil.py`
